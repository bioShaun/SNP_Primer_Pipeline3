# KASP 探针特异性生信评估标准

本文档定义了 KASP 探针在生信预测阶段的特异性评估标准，主要分为 **Fail（非特异 / 高风险）** 和 **Warning（单引物多重结合）** 两个级别，并提供了执行比对的核心命令。

---

## 0. 前置处理

### 0.1 引物去尾

KASP 探针序列包含平台特异的荧光标记尾巴（FAM tail / HEX tail），这些尾巴不参与基因组靶标结合，**必须在比对前去除**。

| 探针类型 | 需去除的 5' 尾巴序列 |
|----------|---------------------|
| Allele-specific（FAM） | `GAAGGTGACCAAGTTCATGCT` |
| Allele-specific（HEX） | `GAAGGTCGGAGTCAACGGATT` |
| Common | 无尾巴，直接使用原始序列 |

去尾后的引物序列应写入 `primers_no_tail.fasta`，每条引物以 `>{snp_name}_{primer_type}` 命名（如 `>SNP001_F1`, `>SNP001_F2`, `>SNP001_R`）。

### 0.2 靶标区域定义

为区分"靶标命中"与"脱靶命中"，需预先定义每个引物组合的靶标区域：

* **靶标染色体**：引物设计时对应的染色体/Contig ID
* **靶标窗口**：以目标 SNP 为中心，上下游各 **2000 bp** 的范围
* 比对结果中，落在靶标窗口内的命中应**排除**在脱靶判定之外
* 对于多倍体物种，同源基因组上的已知 homeolog 命中也应标记排除（这些位点在引物设计阶段已通过多序列比对处理）

## 1. Fail（非特异 / 高风险）的判定参数

要判定一个探针组合为 **Fail**，必须**同时满足**以下 4 个参数条件。这意味着在非靶标区域形成了极高概率被真实扩增的产物：

* **参数 A：3' 端绝对锚定 (核心参数)**
    * **判定值：** F 引物（已去尾）和 R 引物的比对结果中，3' 端最后 2 个碱基必须是 **0 错配 (0 Mismatch)**。
    * **判定方法：** 通过 BLAST 输出的 **BTOP** 字段解析。BTOP 字符串从 5' 端开始编码，因此需根据引物方向（F 为正链、R 为负链）确定 3' 端对应的 BTOP 尾部或头部位置。
    * **依据：** KASP 依赖 Taq 酶。如果 3' 最末端哪怕只有 1 个碱基错配，Taq 酶的延伸效率会呈指数级下降；如果是最后 2 个碱基错配，几乎绝对不会发生延伸。

* **参数 B：单条引物整体相似度 (Identity & Coverage)**
    * **判定值：** 比对相似度 (Identity) **>= 85%**，且比对长度占引物原长的比例 (Coverage) **>= 85%**。
    * **补充约束：** 错配碱基数 **≤ 3**（绝对值约束，防止短引物百分比波动导致误判）。
    * **依据：** 即使 3' 端匹配，如果引物整体结合极不稳定，退火时也无法有效结合模板。使用百分比 + 绝对值双重约束更为稳健。

* **参数 C：扩增子物理距离 (Distance)**
    * **判定值：** F 引物和 R 引物在同一条非靶标染色体/Contig 上的物理距离在 **50 bp 至 1000 bp** 之间。
    * **依据：** 正常的 KASP 产物通常在 50-120 bp。上限放宽到 1000 bp 是因为参考基因组可能存在组装 Gap、隐藏的 InDel 或结构变异，这些可能导致实际扩增产物小于参考基因组上的表观距离。

* **参数 D：相对方向 (Orientation)**
    * **判定值：** F 和 R 必须分别比对到正链 (+) 和负链 (-)，且 3' 端相互指向对方（形成向内扩增）。

> **结论：** 只要在非靶标区域找到哪怕 1 个同时满足 A、B、C、D 的配对，该探针组合直接打上 **Fail** 标签，予以弃用。

## 2. Warning（单引物多重结合）的判定参数

**Warning** 的本质是"引物海绵效应（Primer Sponge）"，即引物掉进了高重复序列区（如转座子、着丝粒重复序列等），虽然没有形成完整的双向扩增子，但会大量吸附并消耗反应体系中的引物。

要判定为 **Warning**，单条引物需满足以下条件：

* **参数 A：有效命中 (Hit) 的定义**
    * **判定值：** 基因组范围内的单次比对结果中，相似度 (Identity) **>= 85%**，且比对覆盖度 (Coverage) **>= 80%**。
    * **注意：** 这里的判定**不需要**严格要求 3' 端绝对匹配。因为只要大部分序列高度同源，即使不能延伸，也会在退火阶段通过氢键结合消耗掉引物。

* **参数 B：基因组全局命中次数 (Hit Count)**
    * **判定值：** 单条引物（F1、F2 或 R 中的任意一条）在全基因组中满足"有效命中"的次数超过阈值。
    * **推荐阈值：**

    | 基因组类型 | 近似大小 | 建议阈值 |
    |-----------|---------|---------|
    | 二倍体动物（人、鼠等） | 1-3 Gb | **≥ 30** |
    | 二倍体植物（水稻、拟南芥等） | 0.1-1 Gb | **≥ 30** |
    | 多倍体植物（小麦、棉花等） | 5-17 Gb | **≥ 100** |

    * **依据：** 正常情况下，特异性好的引物在基因组中只有 1-5 个高度相似的旁系同源结合位点。阈值需与基因组大小和倍性成比例调整，因为大基因组中随机命中的背景频率更高。

> **Warning 后的处置建议：**
> * **优先措施**：检查 pipeline 是否有备选引物组合，优先替换 Warning 引物
> * **保留条件**：如果无备选引物且 hit count < 阈值的 2 倍，可标记 "Warning" 保留给用户判断
> * **强弃用**：如果 hit count > 阈值的 5 倍，提升为 "Fail"

## 3. 核心比对命令

请在终端或集群提交脚本中使用以下参数组合进行短序列高精度比对：

```bash
blastn -task blastn-short \
       -query primers_no_tail.fasta \
       -db /path/to/your/reference_genome_db \
       -evalue 1000 \
       -word_size 7 \
       -dust no \
       -soft_masking false \
       -max_target_seqs 10000 \
       -max_hsps 1 \
       -outfmt "6 qseqid sseqid pident length mismatch gapopen qstart qend sstart send qlen btop" \
       -num_threads 8 \
       -out kasp_offtarget_blast.tsv
```

### 关键参数说明

| 参数 | 值 | 说明 |
|------|------|------|
| `-task` | `blastn-short` | 专为 < 30bp 短序列优化的搜索策略 |
| `-evalue` | `1000` | 极高阈值确保不遗漏任何潜在脱靶位点 |
| `-word_size` | `7` | `blastn-short` 默认值，最大化灵敏度 |
| `-dust` | `no` | 关闭低复杂度序列过滤，防止 AT-rich 引物区段被跳过 |
| `-soft_masking` | `false` | 关闭数据库端 soft mask，确保对所有区域完整搜索 |
| `-max_target_seqs` | `10000` | 确保不遗漏高重复区域的命中，Warning 评估依赖完整命中计数 |
| `-max_hsps` | `1` | 每条目标序列只保留最佳 HSP，减少冗余 |
| `btop` | — | BLAST Traceback Operations，用于精确解析 3' 端错配位置 |
| `qlen` | — | 引物原始长度，用于计算 Coverage = length / qlen |

### 输出字段说明

```
qseqid   — 引物名称
sseqid   — 命中的染色体/Contig
pident   — 比对相似度 (%)
length   — 比对长度
mismatch — 错配数
gapopen  — gap 数
qstart   — 引物比对起始位置
qend     — 引物比对结束位置
sstart   — 基因组比对起始位置
send     — 基因组比对结束位置
qlen     — 引物原始全长
btop     — BTOP 编码，用于 3' 端错配解析
```

## 4. 脱靶评估流程概要

```
引物设计完成
  │
  ▼
去除 FAM/HEX 尾巴 → primers_no_tail.fasta
  │
  ▼
BLAST 全基因组比对（blastn-short）
  │
  ▼
排除靶标区域命中（目标 SNP ± 2000bp）
  │
  ├──▶ Fail 判定：逐对检查 F+R 组合
  │     满足 A(3'端) ∧ B(相似度) ∧ C(距离) ∧ D(方向) → 弃用
  │
  └──▶ Warning 判定：逐条检查单引物命中数
        有效命中次数超阈值 → 标记/替换/弃用
```
